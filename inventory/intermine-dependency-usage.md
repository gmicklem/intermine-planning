# InterMine Java back end: dependency usage census

Repo: `/Users/gos/claude_projects/update_intermine_planning/repos/intermine`, branch `dev`, commit `77cf7068`. Companion: `intermine-dependencies.md` (inventory, versions, CVEs, tiers).

## 1. Method and mapping rules

- Scope: 1,877 source files matching `**/src/**/*.java` and `*.groovy` (403 under `src/test`, 17 Groovy files in `plugin/`), plus 253 JSP/tag/TLD files (`intermine/webapp` 192, `bio/webapp` 54, `testmine/webapp` 7), `web.xml`, `struts-config.xml`, `tiles-defs.xml`, `dwr.xml`, and the 95 `build.gradle` files. No Java file lives outside a `src/` tree.
- Counting unit: a source file counts once for a coordinate if it has at least one `import` (including `import static`) whose package maps to that artefact. "Distinct imports" = distinct imported fully-qualified names (a wildcard counts as one). Inline fully-qualified references without an import were checked separately and only matter for cglib (4 extra files). Main vs test is decided by `/src/test/` in the path (a file under `src/main` of a `*-testresources` module counts as main).
- Package to artefact mapping (the ambiguous ones): `org.apache.commons.collections` -> commons-collections 3.x (`collections4` is not used anywhere); `org.apache.commons.lang.` -> commons-lang 2.6 and `org.apache.commons.lang3.` -> commons-lang3 (0 imports); `org.apache.log4j` -> reload4j 1.2.22 (log4j 1.x API); `org.slf4j` -> slf4j-api via slf4j-reload4j (0 imports); `org.apache.struts.tiles` -> struts-tiles, `org.apache.struts.actions` -> struts-extras, `org.apache.struts.taglib` -> struts-taglib, other `org.apache.struts` -> struts-core (verified by listing the 1.3.10 jars on Central); `com.fasterxml.jackson.annotation/databind/core` -> the three jackson artefacts; `org.apache.lucene.analysis.snowball` -> lucene-snowball, `...search.highlight` -> lucene-highlighter, `...search.similar`/`queries` -> lucene-queries, everything else (incl. `queryParser`, `StopAnalyzer`) -> lucene-core 3.0.2; `org.apache.jena` -> jena-core (+ the apache-jena-libs aggregate); `junit.*`/`org.junit` -> junit 4.8.2 (hamcrest `CoreMatchers` is bundled in that jar); `javax.servlet.jsp.jstl` -> jstl, `javax.servlet.jsp` -> jsp-api, `javax.servlet` -> servlet-api; `antlr.` -> the vendored `antlr-2.7.6-caching.jar` (same 225 classes as Central `antlr:antlr:2.7.6`).
- Gradle `build.gradle` build-time libs (ant, antlr plugin, cargo, tomcat) are counted from the build files, JSP-only libs from the JSP/TLD counts.
