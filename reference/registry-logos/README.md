# Registry logo overrides (source material)

- `planmine.png` (58x58, transparent): the planarian icon cropped from PlanMine's own front-page
  logo, `https://planmine.mpinat.mpg.de/planmine/model/images/logo.png` (217x48, saved here as
  `planmine-wordmark-source.png`), fetched 17 Nov 2026. PlanMine's `/service/branding` names the
  generic InterMine squares (`cdn.rawgit.com/intermine/design-materials/.../45x45.png`) instead, so
  the registry carries this crop as an override until PlanMine sets `branding.images.logo` itself.
